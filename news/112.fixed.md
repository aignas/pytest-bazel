With `PYTEST_BAZEL_CONFIG_FROM_PACKAGE=1`, the `testpaths` of the pytest config file of the package are now relative to that file, e.g. `testpaths = tests` collects `<package>/tests`. Before, they were looked up in the runfiles root, so with `PYTEST_BAZEL_SCOPE_COLLECTION_TO_PACKAGE=1` too, the tests of all packages were collected.
